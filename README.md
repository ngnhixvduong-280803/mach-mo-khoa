# 🔐 Mạch Mã Khóa Bằng Phím Số

> Dự án thiết kế mạch điện tử — Khóa điện tử dùng bàn phím số (keypad lock circuit)

---

## 📌 Tổng quan

Dự án thiết kế mạch **mã khóa bằng phím số** — hệ thống khóa điện tử cho phép người dùng nhập mã PIN từ bàn phím số để điều khiển trạng thái đóng/mở khóa và hiển thị LED. Các bản mạch được thiết kế và mô phỏng bằng **Altium Designer** và **Proteus**, kèm sơ đồ khối tổng thể.
